# Claude 桌面翻译 · Windows

Claude 与 Codex 共用页面内翻译引擎。Claude 使用暖橙色标签；按钮、输入预览、正文原位翻译和原文恢复使用同一实现。

## 通道切换

Claude 区域 → 通道切换：提前保存供应商名称、网关地址、API Key 和认证方式，之后选择供应商并点击切换。切换前请保存草稿并结束运行中的任务；工具箱会备份配置、完全退出 Claude，再写入通道配置并重新打开。也可导入 Claude 已有的静态 Key 网关配置。

官方连接使用 Claude 原有登录；原生网关要求 Anthropic Messages API（流式和工具调用），可留空模型让 Claude 自动发现，或填写 Sonnet / Opus / Haiku 模型 ID。OpenAI 专用接口及非 Claude 模型需要另行提供协议转换网关，此版本不提供转换。连接预检发送一个最小测试请求，可能产生少量费用。

官方云端历史和第三方模式的本地历史独立保存。通道切换不会搬迁会话。第三方配置使用 Claude 原生 configLibrary，工具箱拥有单独的配置条目，保留原有配置；组织管理的推理策略不能被覆盖。

Key 在工具箱内以 Windows DPAPI 加密保存；Claude 原生配置只引用凭据助手，不包含 Key 明文。自动备份位于工具箱数据目录的 claude_channel_backups。

页面翻译目前仅适配官方 Claude Chat 页面；第三方模式的本地页面暂不支持页面翻译。

## 首次接入

1. 正常打开 Claude 桌面版的 Chat 对话。
2. 在 Claude 官方 Help → Troubleshooting 中手动启用 Developer Mode。
3. 打开官方开发者工具的 Console，阅读安全提示后自行确认 allow pasting。
4. 工具箱 → 翻译，选择服务、模型和翻译范围，再点击“开启 Claude 翻译”。

接入时官方开发者工具会短暂打开，收到页面确认后自动关闭。工具箱临时粘贴内置脚本并恢复原剪贴板，不改写 Claude 安装文件或安全设置。若 Console 已有未执行代码，接入会停止，请先自行处理。

## 页面与输入

- 页面默认保持原文。“翻译页面”会翻译当前可见且已启用范围内的界面和回答正文；“原文”立即恢复原文字。
- 用户消息、输入草稿、代码、链接地址和 model 名称不作为界面文字翻译。
- 拖动顶部把手可在 Claude 页面内移动按钮框；↺ 恢复到输入框上方。
- 输入翻译支持中→英、英→中。方向匹配时，第一次回车翻译并显示可编辑预览；在预览中第二次回车写入并发送。
- “仅写入”保留译文在输入框中，之后回车调用 Claude 的发送按钮；Shift+回车换行，输入法确认不触发发送。
- 预览期间草稿或输入框变化、空译文、写入回读不一致或发送按钮不可用时，自动发送会停止并提示。发送操作不自动重试。

## 生命周期

按钮框和预览属于 Claude 页面，随窗口移动、最小化和关闭。关闭窗口（包括关闭到托盘）会停止本次翻译服务；重新打开后需要重新开启翻译。

对话内普通页面切换保留翻译引擎。完整刷新页面会清除临时脚本；返回同一个 Claude 窗口后尝试自动接入。若接入失败，可在工具箱重新点击“开启 Claude 翻译”。关闭翻译或退出工具箱后移除覆盖层并恢复原文字。

本功能目前只支持 Windows 的 Claude Chat，不包含 Cowork 和 Code 工作区。Claude 更新后页面结构可能变化。

## 数据

翻译使用所选服务的费率；输入、回答正文和未命中本地词典的界面文字会按已启用范围发送到该服务。API Key 留在工具箱后端，Claude 页面只获得本次随机本地通信令牌。页面文字替换只在内存中发生，不修改聊天记录。
